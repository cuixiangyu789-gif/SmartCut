# SmartCut

SmartCut 是一个面向中文单人口播视频的 AI 自动粗剪原型。系统把内容判断、帧级时间线执行和剪辑工程导出分为三个独立环节。

## 当前流程

1. 使用豆包录音文件识别模型生成中文逐字稿与时间戳。
2. 根据口播剪辑 SOP 生成删除、保留或人工复核决定。
3. 将内容决定转换为整数帧删除区间和波纹虚拟时间线。
4. 对边界进行波形安全帧吸附、音节与呼吸保护。
5. 导出可导入 DaVinci Resolve 或 Premiere Pro 的 FCP7 XML。

## 主要能力

- 中文逐字稿与词级时间戳规范化
- 口误、重说、废弃表达和无效停顿判断
- 帧级边界校准与人工精确覆盖
- 波形静音帧吸附和发音保护
- 句间间隔超过15帧时压缩至15帧
- 自然、紧凑、强节奏三种剪辑档位
- 边界错题本与结构化反馈日志
- 虚拟时间线质量检查
- FCP7 XML 工程导出

## 安全说明

API Key 只通过环境变量 `DOUBAO_ASR_API_KEY` 读取，不写入项目文件。原始视频、音频、识别输出、工程导出和本机路径配置默认不提交到 Git。
